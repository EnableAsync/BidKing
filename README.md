# BidKing — 竞拍之王估价辅助工具

PySide6 GUI，在《竞拍之王》游戏里精算仓库价值范围、记录每场拍卖，为 ML 模型训练攒数据集。

## 下载 & 使用

**懒人包：** 去 [Releases](../../releases) 下载 `BidKing.exe`，双击打开，零依赖。

**怎么用（6 步）：**

1. 点 **开始新游戏** → 选伊森
2. 在游戏里买道具，至少买 **良品扫描、普品扫描、优品均格** 这三个
3. 把道具读数填进 GUI：先填总格数 → 蓝色格数 → 白绿格数 → 紫色填平均格数
4. GUI 自动反推所有可能的 (总格数, 物品数) 组合 → 给出仓库价值范围
5. 根据范围决定出价 → 出价填进「我的出价」
6. （可选步骤）拍卖结束后把结算截图拖进 GUI
7. 填仓库总价 → 点 **标记完成**

## 工作流

每一局游戏 = 一个 session，每场拍卖 = 一条 record。

```
开始新游戏 → 选英雄 → 进地图
  ↓
看道具读数 → 输入 GUI (任意可用字段)
  ↓
看价值范围 → 决定出价
  ↓
拍卖结束 → 拍结算截图丢进 GUI → 填仓库总价 + 注释
  ↓
点 [标记完成] → 新一局拍卖 (沿用英雄)
```

## 估价策略

### 数格子精算法 (Grid Actuarial)

#### 反推原理
道具显示的紫色/金色平均格数 `c` 是 2 位小数，满足 `c ≤ a/b ≤ c+0.01`，其中 `a` 是该品质的总格数、`b` 是物品数。脚本枚举所有合法 `(a, b)` 正整数对作为候选。

#### 输入字段 (全部可选, 输入越多, 估值范围越窄)

| 类别 | 字段 | 来自道具 |
|------|------|----------|
| 基础 | 总格数 T | 总仓储空间 (25000 银) |
| 基础 | 蓝色总格数 B | 良品扫描 (1000 银) |
| 基础 | 白绿总格数 WG | 普品扫描 (500 银) |
| 紫色 | 平均格数 c_p | 优品均格 (1000 银) |
| 紫色 | 总格数 a_p | 优品扫描 (2500 银) |
| 紫色 | 件数 b_p | 优品存量 (2500 银) |
| 紫色 | 总价值 | 优品估价 (2500 银) |
| 紫色 | 预估件数 b_p_est | 主观判断 |
| 金色 | 平均格数 c_g | 极品均格 (10000 银) |
| 金色 | 总格数 a_g | 极品扫描 (10000 银) |
| 金色 | 件数 b_g | 极品存量 (10000 银) |
| 金色 | 总价值 | 极品估价 (10000 银) |
| 金色 | 预估件数 b_g_est | 主观判断 |

紫色/金色的字段可以任意组合，策略自动反推：
- 给了 `a_p`：紫总格数直接确定 → 单一候选
- 给了 `c_p` + `b_p`：根据 c 范围反推 a → 通常单一候选
- 仅给 `c_p`：用 `b_p_est` 选最近 6 个候选（紫色, 金色 5 个）
- 给了 `c_p` + `a_p`：a 已知, b 由 `a/c` 推出
- 给了 `purple_total_value`：直接覆盖 `a_p × v_p` 的估算

#### 估值公式

```
总价 = WG × v_wg + B × v_b + a_p × v_p + (金红剩余 × v_jr)
                                          OR
                                       (a_g × v_g + 红色剩余 × v_r)
```

未启用金色反推时使用 `v_jr` 估金红混合；启用时拆成 `v_g` (金) + `v_r` (红)。

#### 价值范围
每个候选组合 `(紫色, 金色)` 算一个估值，输出 `min / max / median`。完全确定时范围塌缩成单一值。

#### 默认单格估价
| 字段 | 默认 ¥/格 | 用途 |
|------|----------|------|
| v_wg | 100 | 白绿 |
| v_b | 800 | 蓝 |
| v_p | 2000 | 紫 |
| v_jr | 20000 | 金红混合 (c_g 未给) |
| v_g | 10000 | 金 (c_g 给定时) |
| v_r | 30000 | 红 (c_g 给定时) |

默认值可在 GUI 修改，持久化到 `config.json`。

## 数据持久化

| 文件 | 内容 |
|------|------|
| `records.jsonl` | 每行一条记录 (UUID 索引); 整文件覆盖重写 |
| `records.jsonl.bak` | 启动时滚动备份 (兜底用) |
| `config.json` | 各策略的默认价格 |
| `screenshots/<uuid>.png` | 结算截图 (拖入/选择/Ctrl+V 粘贴) |

所有文件在项目根目录，已加 `.gitignore`。

### 记录 schema

```json
{
  "record_id": "uuid",
  "timestamp": "2026-05-17T15:30:00",
  "session_id": "20260517-153000",
  "strategy": "数格子精算法",
  "map_id": 2401,
  "hero_id": 208,
  "inputs": {
    "T": 120, "B": 12, "WG": 30,
    "purple_avg": 1.6, "purple_count_est": 10,
    "purple_total_grids": null, "purple_count": null,
    "gold_avg": 2.66, "gold_count_est": 5,
    "gold_total_grids": null, "gold_count": null,
    "v_wg": 100, "v_b": 800, "v_p": 2000,
    "v_jr": 20000, "v_g": 10000, "v_r": 30000
  },
  "predicted": {
    "purple_candidates": [{"purple_total_grids": 16, "purple_count": 10}, ...],
    "gold_candidates":   [{"gold_total_grids": 8, "gold_count": 3}, ...],
    "value_range": {"min": 520000, "max": 980000, "median": 750000},
    "selected_purple_idx": 0,
    "selected_gold_idx": 0
  },
  "bid": 750000,
  "actual": {
    "total_value": 1100000,
    "screenshot_path": "screenshots/abc123.png"
  },
  "note": "对手出 720K, 我捡漏",
  "status": "draft | bid_placed | completed"
}
```

`status` 自动升级: 填了出价 → `bid_placed`; 点「标记完成」→ `completed` (纳入数据集)。

## 数据分析示例

```python
import pandas as pd
df = pd.read_json("records.jsonl", lines=True)
done = df[df["status"] == "completed"]

# 把 predicted.value_range.median 拆出来当预测值
done["pred_median"] = done["predicted"].apply(
    lambda p: (p.get("value_range") or {}).get("median")
)
done["actual_total"] = done["actual"].apply(lambda a: a.get("total_value"))
done["diff_pct"] = (done["actual_total"] - done["pred_median"]) / done["pred_median"] * 100
```

## 界面布局

```
┌─ 顶栏: 策略 / Session / [开始新游戏] [新一局] [历史记录] ─┐
├──────────────────────────────────────┬────────────────┤
│ 估价 (出价前)                         │ 事后录入        │
│  ┌─ 元数据: 地图 + 英雄 ─────────────┐ │  ┌─ 真实结果 ─┐ │
│  │ (并排)                            │ │  │ 仓库总价   │ │
│  └──────────────────────────────────┘ │  │ 结算截图   │ │
│  ┌─ 输入 ──────────────────────────┐ │  └────────────┘ │
│  │ 总格数 / 蓝 / 白绿              │ │  ┌─ 注释 ─────┐ │
│  │ 紫色: 平均/预估件数/总格数/件数 │ │  │ (多行)     │ │
│  │ 金色: 平均/预估件数/总格数/件数 │ │  └────────────┘ │
│  │ 单格估价: 6 个                  │ │  ┌─ 我的出价 ─┐ │
│  └──────────────────────────────────┘ │  └────────────┘ │
│  ┌─ 输出 ──────────────────────────┐ │                │
│  │ 预估价值: ¥X ~ ¥Y (中位 ¥Z)     │ │                │
│  │ 当前选: 紫_格 / 金_格 / 红_格   │ │                │
│  │ 紫色候选 ◯◯◯  金色候选 ◯◯◯   │ │                │
│  └──────────────────────────────────┘ │                │
├──────────────────────────────────────┴────────────────┤
│ status / [标记完成] [回滚 draft] [删除]                │
└────────────────────────────────────────────────────────┘
```

颜色编码（输入框 & 事后录入分组）:
- 白绿 浅绿、蓝 浅蓝、紫 浅紫、金 浅黄、红 浅红、金红混合 浅橙
